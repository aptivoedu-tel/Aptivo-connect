# Aptivo Connect visual migration checklist

This is the route-by-route implementation checklist for the reference-led student product redesign. Admin is intentionally excluded as an operational surface.

| Surface | Design target | Status |
| --- | --- | --- |
| `/` landing | Reference screen 1 | In progress |
| `/auth/login`, `/auth/register`, `/onboarding` | Warm editorial auth/onboarding | Pending |
| `/dashboard` | Reference screen 2 discovery home | In progress |
| `/dashboard/meetup` | Image-led Meet discovery and detail state | Pending |
| `/dashboard/build` | Reference screen 4 project discovery | In progress |
| Build workspace/detail surfaces | Calm image-led workspace, tabs, team and chat | Pending |
| `/dashboard/experience` | Image-led Experience discovery/detail/application | Pending |
| `/dashboard/campus`, `/dashboard/people`, `/dashboard/links` | People-row and compact connection system | Pending |
| `/dashboard/messages` | Reference screen 5 conversation rows and active chat | Pending |
| `/dashboard/profile` | Reference screen 6 living profile/editor | In progress |
| `/profile/[id]` | Public living profile | Pending |
| `/showcase`, `/showcase/[id]` | Build-family image-led showcase | Pending |
| `/dashboard/ambassador` | Compatible community form/status design | Pending |
| Notifications/dropdowns/modals/forms/empty/error/loading states | Shared neutral component language | In progress |
| `DashboardShell`, `MobileNav` | Reference screen 3 navigation/drawer | In progress |

## Shared primitives required

- Editorial display headings plus clean UI sans text
- Warm Ivory canvas, white surfaces, soft borders, Forest identity, rare Coral action
- Image opportunity cards, compact discovery rows, people rows, conversation rows and activity rows
- Session-backed identity and safe avatar/media fallbacks
